# LiteRadio

A worldwide radio listening web app with live search, an interactive map, country and genre filters, and device-local favourites.

Run locally: `python3 -m http.server 8000`, then open http://localhost:8000.

Station directory: Radio Browser. Map: Leaflet and OpenStreetMap. Internet access is required. Streams are provided by broadcasters and may be unavailable or region-restricted.

GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). This private repository requires a GitHub plan supporting private Pages, or a visibility change you choose yourself.
